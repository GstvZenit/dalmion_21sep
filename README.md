## Easy maintenance

- **Change the password:** edit the `SITE_PASSWORD` line at the top of `site.js`.
- **Replace a photo:** put the new image in `photos`, then change its `src` in `album.html`.
- **Add a photo:** copy any `<figure>...</figure>` line in the gallery section of `album.html`, then update the file name and caption.
- **Change the style:** edit the color values at the very top of `style.css`.
- **Add the music playlist:** in `album.html`, find `id="playlist-link"` and replace `href="#"` with the YouTube playlist URL.
